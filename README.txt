The five uploaded photos have been added to the gallery and the first photo is used
as the main profile photo.

FREE PUBLISHING:
1. Create a GitHub account.
2. Create a PUBLIC repository named: syed-ali-mehdi.github.io
3. Upload index.html, style.css and all five profile-*.jpeg files.
4. Open Settings > Pages.
5. Choose Deploy from branch, select main, and save.
6. Your site can then be reached at:
   https://syed-ali-mehdi.github.io/

PRIVACY:
Only publish photos and information you are comfortable making public. Do not add
private information such as a home address, phone number, CNIC, passwords or family
documents.
